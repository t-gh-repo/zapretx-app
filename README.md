# Zapretx for Android

![GitHub Downloads (all assets, all releases)](https://img.shields.io/github/downloads/t-gh-repo/zapretx-app/total)

Данное приложение является форком [zaprett-app от CherretGit](https://github.com/CherretGit/zaprett-app) и использует модуль [zaprett](https://github.com/egor-white/zaprett).
Форк направлен на более широкую поддежку, стабильность и больший функционал.

> [!CAUTION]
> ⚠️ Для корректной работы приложения **желательны root-права**, однако предусмотрен режим без root на основе **byedpi**
